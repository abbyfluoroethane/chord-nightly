# Chord nightly builds

Nightly builds of Chord for Android and Chord Desktop: the state of `main` each night, when its
checks passed and it changed since the last nightly. This repository holds only releases. The
source is in the Chord repository.

Nightlies are for testing. They can break. The apps can install them for you: Settings → About →
Updates → Nightly. The last 14 builds of each app are kept.

- Android: `android-<version>` releases, for example `android-0.2.0-nightly.20261004`.
- Desktop: `desktop-<version>` releases.

For tested builds, see [chord-android](https://github.com/abbyfluoroethane/chord-android/releases)
and [chord-desktop](https://github.com/abbyfluoroethane/chord-desktop/releases).
